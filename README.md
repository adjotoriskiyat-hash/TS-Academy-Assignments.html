# Frontend Projects Portfolio

Welcome to my frontend development portfolio! This repository contains a collection of web pages I have built from scratch to practice and showcase my skills in web development. 

**Note:** All the code in this repository was written, tested, and deployed entirely using a mobile phone development workflow.

## 📂 Projects Included

### 1. Body Hub Landing Page (`Project 2.html` & `Project 2.css`)
A fully styled, single-page e-commerce landing page for a cosmetic and skincare brand called **Body Hub**. 
* **Features:** * Engaging hero section with brand messaging.
  * Embedded multimedia (YouTube video integration).
  * Product display using structured HTML tables (price lists, images, and categories).
  * Responsive grid layout for brand features ("Why Choose Us?").
  * A comprehensive customer order form (handling text inputs, radio buttons, dropdowns, and text areas).
  * Styled with a custom CSS file featuring variables, flexbox/grid alignments, and modern UI touches.

### 2. Digital Curriculum Vitae (`Curriculum Vitae.html` & `My Curriculum Vitae.html`)
Digital resume web pages structured purely with HTML. These pages serve as an online portfolio of my academic background, technical skills, and professional experience.
* **Features:**
  * Clean, semantic HTML structuring (headings, lists, strong tags).
  * Detailed sections for Education, Work Experience, and Professional Summaries.
  * A visual representation of skill proficiency levels.

## 🛠️ Technologies Used
* **HTML5:** For semantic structure, forms, and embedding media.
* **CSS3:** For styling, custom color variables, and responsive layout design.

## 📱 Development Environment
I pride myself on resourcefulness. The projects in this repository were coded completely on a mobile device utilizing mobile-friendly code editors and cloud environments.
